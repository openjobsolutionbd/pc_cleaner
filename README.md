# PC Cleaner — সেটআপ ও ব্যবহার নির্দেশিকা

**বর্তমান ভার্সন: v1.4.4**

## এই অ্যাপটা কী করে

উইন্ডোজ ব্যবহারের ফলে জমা হওয়া জাঙ্ক ফাইল, ব্রাউজার ক্যাশ, পুরনো আপডেট ফাইল ইত্যাদি নিরাপদে খুঁজে বের করে ডিলিট করে। সাথে আরও কিছু মেইনটেন্যান্স টুল আছে (নিচে বিস্তারিত)।

**নিরাপত্তার গ্যারান্টি:** Password কখনো ছোঁয়া হয় না (এটা আলাদা এনক্রিপ্টেড ফাইলে থাকে), Cookies কখনো মোছা হয় না (তাই কোনো সাইট থেকে লগআউট হবেন না), আর Startup Manager-এ কিছু বন্ধ করলেও সেটা স্থায়ীভাবে ডিলিট হয় না — সবসময় আবার চালু করা যায়।

---

## ধাপ ১: Python ইনস্টল আছে কিনা চেক করুন

কমান্ড প্রম্পট (Win+R টাইপ করে `cmd` লিখে Enter) খুলে লিখুন:
```
python --version
```
যদি ভার্সন নাম্বার দেখায় (যেমন `Python 3.12.x`), তাহলে Python ইনস্টল করা আছে — ধাপ ২-এ যান।

যদি "not recognized" এরকম এরর দেখায়, তাহলে [python.org](https://www.python.org/downloads/) থেকে সর্বশেষ ভার্সন ডাউনলোড করে ইনস্টল করুন। **ইনস্টল করার সময় "Add Python to PATH" চেকবক্সে অবশ্যই টিক দেবেন।**

## ধাপ ২: .exe ফাইল বানানো

এই ফোল্ডারের সব ফাইল একসাথে একটা জায়গায় রাখুন, তারপর **`build_exe.bat`** ফাইলে ডাবল-ক্লিক করুন।

এটা করবে:
1. PyInstaller ইনস্টল করবে (একবারই লাগবে)
2. `pc_cleaner.py` থেকে একটা স্ট্যান্ডঅ্যালোন `.exe` বানাবে (একটা ফোল্ডারের ভেতর — একটা মাত্র ফাইল নয়, কারণ single-file exe প্রায়ই অ্যান্টিভাইরাস ভুলভাবে সন্দেহজনক ধরে ফেলে)

শেষ হলে `dist` ফোল্ডারের ভেতর **`PCCleaner`** নামে একটা ফোল্ডার পাবেন, তার ভেতরে `PCCleaner.exe`। পুরো `PCCleaner` ফোল্ডারটা (শুধু .exe ফাইলটা না) যেকোনো জায়গায় নিয়ে গিয়ে চালাতে পারবেন — Python ইনস্টল না থাকলেও চলবে।

---

## ধাপ ৩: চালানো

`PCCleaner` ফোল্ডারের ভেতরের `PCCleaner.exe`-এ ডাবল-ক্লিক করুন।

**গুরুত্বপূর্ণ:** পুরোপুরি কাজ করার জন্য (Windows Temp, Update Cache, Prefetch, Startup registry ইত্যাদি) **Administrator হিসেবে চালাতে হবে** — ফাইলে right-click করে "Run as administrator" বেছে নিন। Admin ছাড়া চালালেও চলবে, শুধু কিছু ক্যাটাগরি স্কিপ হবে (অ্যাপ নিজেই সেটা জানিয়ে দেবে, আর একটা বাটনও থাকবে Admin হিসেবে রিস্টার্ট করার জন্য)।

**নোট:** এই exe সাইন করা (code-signed) না হওয়ায় প্রথমবার চালানোর সময় Windows Defender/অ্যান্টিভাইরাস একটা সতর্কতা দেখাতে পারে — এটা সাধারণত false positive (PyInstaller দিয়ে বানানো যেকোনো ছোট, সাইন-না-করা অ্যাপেই এটা হতে পারে, ফাইল ডিলিট/রেজিস্ট্রি বদলানোর মতো কাজ করলে আরও বেশি)। "More info" → "Run anyway" চাপলেই চলবে।

## ৪টা ট্যাবে কী আছে

| ট্যাব | কাজ |
|---|---|
| **Quick Clean** | রোজকার ব্যবহারের জন্য — একটাই "Clean Now" বাটন, কোনো checkbox বা choice নেই। শুধু "নিরাপদ" ব্যাজের ক্যাটাগরিগুলো (Temp, Cache, Recycle Bin ইত্যাদি) পরিষ্কার করে। |
| **Junk Cleanup** | Temp files, Browser Cache, Thumbnail Cache, Error Reports, Windows Update পুরনো ফাইল, Delivery Optimization, Crash Dumps, Recycle Bin, Prefetch (ঐচ্ছিক) — চেকবক্স দিয়ে বেছে "Clean Selected"। ক্লিন শেষে একটা পপ-আপে দেখাবে ঠিক কত জায়গা খালি হলো, এবং সিস্টেম ড্রাইভের Before/After ফ্রি স্পেসও তুলনা করে দেখাবে। |
| **Browser & Network** | শুধু Browsing History মোছে (Cookies/Password কখনো না), DNS Cache Flush, আর Chrome Profile Manager (একসাথে অনেক প্রোফাইল নিরাপদে খোলা — CPU/RAM বেশি ব্যস্ত থাকলে অপেক্ষা করে; অথবা এক ক্লিকে সব Chrome বন্ধ করে PC শাটডাউন) |
| **Startup && Shutdown** | বুটে কোন প্রোগ্রাম চালু হয় তা দেখা ও বন্ধ/চালু করা (রিভার্সিবল), এবং **Shutdown Auto-Clean** — প্রতিবার PC শাটডাউন করার সময় স্বয়ংক্রিয়ভাবে Temp/Cache/Recycle Bin পরিষ্কার হয়ে যায় (Enable/Disable/Run Now বাটন)। |

উইন্ডো খোলার সাথে সাথেই উপরের ডানদিকে সিস্টেম ড্রাইভের ফ্রি স্পেস একনজরে দেখা যায়।

ব্রাউজার হিস্ট্রি মোছার আগে Chrome/Edge বন্ধ থাকতে হবে (অ্যাপ নিজেই চেক করে জানিয়ে দেবে)।

**v1.4.4 — বাগ ফিক্স (গুরুত্বপূর্ণ):** সম্পূর্ণ কোড রিভিউ করে ৩টা আসল বাগ খুঁজে ঠিক করা হয়েছে:
- **Browsing History clear** — Chrome/Edge ঠিকমতো বন্ধ না হলে (ক্র্যাশ বা force-kill-এর পর) একটা leftover ফাইল থেকে যেত যেটার কারণে "মোছা" হিস্ট্রি আবার ফিরে আসতে পারত ব্রাউজার পরের বার খোলার সময়। এখন এই leftover ফাইল ঠিকমতো পরিষ্কার হয়, তাই ক্লিয়ার করা হিস্ট্রি সত্যিই ক্লিয়ার থাকে।
- **Shutdown Auto-Clean** — Fast Startup বন্ধ করতে ব্যর্থ হলেও আগে "✅ Done, এখন থেকে প্রতি শাটডাউনে চলবে" দেখাত — কিন্তু Fast Startup চালু থাকলে Windows আসলে শাটডাউন স্ক্রিপ্ট স্কিপ করে দেয়, তাই ফিচারটা silently কাজ নাও করতে পারত। এখন এই অবস্থায় স্পষ্ট সতর্কতা দেখানো হয়।
- **Chrome Profile Manager** — অনেকগুলো প্রোফাইল খোলার সময় "কোনটা আগে থেকে খোলা" চেক করতে প্রতিটা প্রোফাইলের জন্য আলাদা PowerShell প্রসেস চালু হতো (ধীর) — এখন একবারই চেক করে সব প্রোফাইলের জন্য ব্যবহার করে, তাই ৩০টা প্রোফাইল খুলতে গেলে অনেক দ্রুত হবে।

৩৩টা নতুন টেস্ট এই ফিক্সগুলো যাচাই করে (`shutdown_setup.py`-র জন্য প্রথমবারের মতো টেস্ট যোগ হয়েছে, `startup_manager.py`-র ফোল্ডার-ভিত্তিক অংশও)।

**v1.4.2:** exe বিল্ড এখন `--onedir` ব্যবহার করে (আগে `--onefile`) — single-file PyInstaller exe প্রায়ই অ্যান্টিভাইরাস ভুলভাবে সন্দেহজনক ধরে ফেলে, ফোল্ডার-ভিত্তিক বিল্ডে এই ঝুঁকি কম। কিছু Windows API কল (Recycle Bin, RAM/CPU রিডিং) আরও নিরাপদভাবে ফলাফল যাচাই করে এখন — আগে ব্যর্থ হলেও silently ভুল ডেটা দেখাতে পারত।

**v1.4.1:** Junk Cleanup-এর "Chrome Browser Cache" ক্যাটাগরি (আগে থেকেই আছে, নতুন কোনো বাটন নেই) এখন সব Chrome প্রোফাইল জুড়ে এবং Cache-এর পাশাপাশি Code Cache/GPUCache/Service Worker cache-ও পরিষ্কার করে — এগুলোই মূলত সময়ের সাথে জমে ব্রাউজার ধীর করে দেয়। Quick Clean-ও স্বয়ংক্রিয়ভাবে এই সুবিধা পায়।

**Chrome Profile Manager নোট:** আগে আলাদা থাকা "Chrome opener" স্ক্রিপ্ট দুটো (Smart Chrome Profile Opener + Shout Down) এখন এই অ্যাপের ভেতরেই — আলাদা করে psutil ইনস্টল করার দরকার নেই, CPU/RAM সরাসরি Windows API থেকে পড়া হয় (এই প্রজেক্টের বাকি সব কিছুর মতোই কোনো থার্ড-পার্টি ডিপেন্ডেন্সি ছাড়া)। "Chrome বন্ধ করে PC শাটডাউন করুন" বাটনটা তাৎক্ষণিক ও আয়রিভার্সিবল — ক্লিক করলে একটা কনফার্মেশন পপ-আপ দেখাবে।

**v1.4.0-এ যা সরানো হয়েছে:** ব্যবহারকারীর অনুরোধে **System Tools** ট্যাব (Disk Space Analyzer, Empty Folder Finder, Icon Cache Reset) আর **Automation & History** ট্যাবের বেশিরভাগ অংশ (সাপ্তাহিক/দৈনিক শিডিউল, Error Log ভিউয়ার, Cleanup History ভিউয়ার) সরিয়ে ফেলা হয়েছে — শুধু **Shutdown Auto-Clean** রাখা হয়েছে, যেটা এখন Startup && Shutdown ট্যাবে আছে। এরর এখনো `error_log.json`-এ লগ হয় (শুধু দেখার UI নেই), আর প্রতিটা ক্লিনআপ এখনো history-তে লগ হয় (শুধু দেখার UI নেই) — চাইলে পরে আবার UI যোগ করা যাবে। `system_tools.py` আর `scheduler.py` মডিউল দুটো (আর তাদের টেস্ট) প্রজেক্টেই থেকে গেছে, শুধু GUI থেকে ডিসকানেক্ট করা হয়েছে — ভবিষ্যতে চাইলে সহজে আবার ফিরিয়ে আনা যাবে।

## Automated Test চালানো (ঐচ্ছিক, কিন্তু সুপারিশকৃত)

কোড ঠিকমতো কাজ করছে কিনা যাচাই করতে `run_tests.bat`-এ ডাবল-ক্লিক করুন। এতে ১৯৮টা স্বয়ংক্রিয় টেস্ট চলবে (GUI ইন্টিগ্রেশন টেস্টসহ) — বিশেষ করে "Cookies কখনো মোছা হয় না" আর "root ফোল্ডার কখনো ডিলিট হয় না" — এই নিরাপত্তা নিশ্চয়তাগুলো প্রতিবার কোড বদলালে আবার যাচাই হয়।

কোড-কোয়ালিটি চেক (ঐচ্ছিক, ডেভেলপমেন্টের জন্য): `lint.bat`-এ ডাবল-ক্লিক করলে Ruff (bug-finder) আর mypy (type-checker) চলবে — এগুলো অ্যাপে বান্ডেল হয় না, শুধু কোড লেখার সময় ভুল ধরিয়ে দেয়।

## ফাইল লিস্ট

- `pc_cleaner.py` — মূল অ্যাপ (GUI)
- `cleaner_core.py`, `browser_core.py`, `chrome_profile_manager.py`, `system_tools.py`, `startup_manager.py`, `scheduler.py`, `history_log.py` — ভেতরের লজিক (আলাদা ফাইলে, যাতে টেস্ট করা যায়)
- `test_*.py` — automated tests
- `build_exe.bat` — .exe বানানোর স্ক্রিপ্ট
- `run_tests.bat` — টেস্ট চালানোর স্ক্রিপ্ট
- `lint.bat`, `pyproject.toml` — ঐচ্ছিক ডেভেলপমেন্ট-টাইম কোড-কোয়ালিটি টুল (অ্যাপে বান্ডেল হয় না)

## ভবিষ্যতে বদল করতে চাইলে

শুধু `.py` ফাইলগুলো এডিট করুন, তারপর আবার `build_exe.bat` চালালেই নতুন `.exe` তৈরি হয়ে যাবে (পুরনোটা `dist` ফোল্ডারে ওভাররাইট হবে)।
